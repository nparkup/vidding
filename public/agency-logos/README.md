# 발주기관 공식 CI

이 폴더의 CI 파일은 저장소에 넣지 않고, 정적 사이트 빌드 직전에 `scripts/agency-logos/fetch.mjs`가
위키미디어 공용(Wikimedia Commons)에서 받아 둡니다(GitHub Actions 캐시에 보관, 새 파일만 받음).

- 어떤 기관이 어떤 파일인지: `scripts/agency-logos/sources.json` (기관명 → 공용 파일명). 위키데이터 '로고 이미지(P154)'에 등록된 파일과
  공용의 정부상징·시도교육청 CI처럼 사람이 확인한 파일만 넣습니다. 이름이 비슷하다고 자동으로 붙이지 않습니다.
- 공고 기관명과 맞추는 규칙: `src/lib/agencyLogos.ts`. 중앙행정기관과 소속기관은 정부상징, 교육지원청은 시도교육청 CI,
  지역본부·사업소는 상위 기관 CI를 씁니다. 학교와 시·군·구는 자기 CI가 따로 있으므로 상위 기관 CI를 쓰지 않습니다.
- 출처·라이선스: 빌드 때 `credits.json`을 만들고 사이트 `/ci-credits` 페이지에 보여 줍니다.

새 기관을 넣으려면 공용에 올라온 공식 파일을 확인한 뒤 `sources.json`에 한 줄 추가하면 다음 배포부터 표시됩니다.
